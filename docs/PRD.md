# 제품 구현 기준 (2026-10-20)

**제품:** `gagyebu` · 가계부 | **포지션:** 미정리 거래를 빠르게 정리하는 가계부.

## 사용자 문제

장기간 지출 내역이 쌓여도 누락/중복 없이 빠르게 확인하고, 오늘/이번 기간의 사용 가능 예산을 알고 싶다.

## 이번 버전 구현

| 기능 | 상태 | 확인 |
|---|---|---|
| 수입/지출/이체/상환/환불 | 구현 | 순지출·자산 잔액 테스트 |
| 기록 미확정/확정 | 구현 | 미확정 집계 제외 |
| 계산식 보존 | 구현 | 단순 수학 수식 파서/단위테스트 |
| 달력/분석/월별 예산 | 구현 | 정산 시작일 1~28 설정 |
| 분류/검색/필터/사진 | 구현 | 로컬 IndexedDB 저장 |
| 거래 CSV/문자 붙여넣기 | 구현 | 미정리함에서 사용자 검토 |
| JSON 전체 백업 복원 | 구현 | 스키마 버전 1 검증 |
| 앱 설치/오프라인 | 구현 | 서비스 워커 캐시 |
| Android SMS 자동 수집, OCR | 미구현 | 별도 권한·정책 검토 필요 |
| Firebase 동기화·가족 공유 | 미구현 | 정보보안 설계 후 적용 |

## 참고 디자인(사용자 제공)

- 직접 경쟁: 편한가계부 — SMS/앱 알림, 달력, 사진, 통계, PC 자산관리.
- 간접 UX: 별도 계산기 — 계산 기록·메모, 수식 재사용, 할인 계산.
- 경쟁 앱 이미지 자체를 복제하지 않고 독립 UI/UX 제작.

## 품질

브라우저 IndexedDB를 기반으로 로컬 우선 동작, 저장 및 JSON 복원 검증, XSS 방어용 HTML 이스케이프, 수식은 `eval` 없이 안전하게 해석합니다. 금융 정보는 저장소·Pages에 업로드하지 않습니다.
